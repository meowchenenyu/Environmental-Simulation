# 虛擬生態系模擬器：願景與開發路線圖

> 狀態：階段 1 可互動原型、階段 2 MVP 生態模擬與階段 3 單人體驗已完成。
> 更新日期：2026-11-27

## 願景

打造一個在瀏覽器中運作的虛擬生態系模擬器。使用者可以設計島嶼地形與氣候、放入植物和動物，推進時間觀察生態系變化，並透過清楚的資訊了解物種數量、食物鏈、資源與環境事件之間的關係。

核心體驗是：**設計環境 → 放入物種 → 推進時間 → 觀察變化 → 調整策略**。

產品以可理解、有探索感的生態模擬為主，不以真實科學模型的完整度作為第一階段目標。重要變化應盡可能說明原因，讓使用者看得懂族群為何增加、下降或遷徙。

### 目標使用者與平台

- 喜歡模擬遊戲、自然科學、策略規劃或世界創作的人。
- 以桌面瀏覽器為主要操作環境，並支援手機瀏覽與基本管理。

### 產品原則

- 模擬規則簡單、可解釋，之後再逐步增加深度。
- 提供範例島、教學和目標，讓新使用者容易開始。
- 建造、觀察、分析各有清楚的介面入口。
- 透過自動保存、快照和分支保護使用者成果。
- 鼓勵探索與生態平衡，不只獎勵增加物種數量。

## MVP 範圍與暫不處理項目

MVP 優先完成：固定尺寸島嶼、4 種基本地形、約 8 種物種、簡化生態模擬、播放控制、事件紀錄、3 種基本圖表、範例島與本機存檔。

以下項目留待後續階段評估：即時多人、複雜演化、真實世界氣象資料、3D 畫面、社群留言與付費功能。

## 建議技術方向

- 前端：React 或 Next.js。
- 地圖：小型原型可用 SVG 或 Canvas；地圖規模擴大後優先評估 Canvas。
- 模擬運算：先在瀏覽器執行，必要時使用 Web Worker 避免阻塞畫面。
- 本機存檔：MVP 使用瀏覽器儲存。
- 雲端版本：後續可採 API 搭配 PostgreSQL，儲存帳號、島嶼、模擬快照與社群資料。

以上是初步技術方向，實作前可依專案環境調整。
